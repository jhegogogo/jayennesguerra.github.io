01 CAPSTONE PROJECT

Rylim Memory Atlas

Project Manager

FlutterFlow Firebase Google Maps API

A location-based memory atlas designed to capture and rediscover meaningful moments across the Philippines. It allows users to preserve personal experiences by connecting memories with specific locations. The system also provides an intuitive way to revisit meaningful places and explore memories through an interactive map.

Rylim combines geolocation, multimedia journaling, and cloud-based services to create a more interactive way of preserving personal experiences and meaningful places. Users can attach photos, videos, audio, and written reflections to their saved locations.

Rylim connects personal memories with physical locations through geolocation technology and an interactive map.

  • GPS-based location tagging for memories.
  • Interactive map for exploring pinned memories.
  • Location data using geographic coordinates.
  • Date and time information for organizing memories.
  • Location-based notifications and reminders.

Rylim allows users to preserve experiences through different forms of digital content, creating richer and more personal memories.

  • Photos and image-based memories.
  • Video recordings for documenting experiences.
  • Audio recordings for capturing personal thoughts and experiences.
  • Written journal entries and notes.
  • Multimedia content linked directly to selected locations.

Rylim uses location data and user information to provide personalized insights and encourage users to explore meaningful places.

  • Prescriptive analytics based on user preferences and documented memories.
  • Location-based recommendations for nearby places and attractions.
  • Google Maps API integration for map and location functionality.
  • Analysis of user paths, locations, and documented experiences.
  • Personalized suggestions that encourage memory rediscovery and exploration.

Rylim uses cloud services and authentication mechanisms to provide secure access to user accounts and synchronize memory data across supported platforms.

  • Firebase Authentication for secure account access.
  • Firebase Cloud Storage for user-generated multimedia.
  • Real-time synchronization of memory data.
  • Role-based access control for system administration.
  • Data privacy considerations aligned with the Data Privacy Act of 2012.
