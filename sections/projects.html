RYLIM Memory Atlas

Project Manager

FlutterFlow Firebase Google Maps API

A location-based memory atlas designed to capture and rediscover meaningful moments across the Philippines.

RYLIM combines location-based mapping with multimedia memories to help users preserve and rediscover meaningful experiences.

  • Location-based memory mapping.
  • Firebase authentication and real-time cloud storage.
  • Multimedia memories using photos, notes, and audio.
  • Scalable cloud architecture.

RYLIM uses a combination of application development, cloud services, and mapping technologies.

  • FlutterFlow — application development.
  • Firebase — authentication and cloud storage.
  • Google Maps API — location and map functionality.

As Project Manager, I helped oversee the planning, coordination, development direction, and overall delivery of the RYLIM project.

  • Technology integration and documentation.
